### **How to run**

**Default (FREE):**

npm run prisma:seed

**Pro / Business shortcuts:**

npm run prisma:seed:pro

npm run prisma:seed:business

**Custom plan via CLI:**

npm run prisma:seed -- --plan PRO

npm run prisma:seed -- --plan=BUSINESS

npm run prisma:seed -- --plan=BUSINESS

npm run prisma:seed -- --plan PRO

npm run prisma:seed:business

npm run prisma:seed:pro

npm run prisma:seed
