# Marketing - industry carousel images

Place one WebP per card in this folder. Used by the hero industries carousel on the landing page.

## File naming

| File | Industry |
| --- | --- |
| `construction.webp` | Budownictwo |
| `renovations.webp` | Remonty i wykończenia |
| `electrical.webp` | Instalacje elektryczne |
| `plumbing.webp` | Instalacje hydrauliczne |
| `events.webp` | Eventy |
| `landscaping.webp` | Ogrody i architektura krajobrazu |
| `hvac.webp` | Klimatyzacja i HVAC |
| `photovoltaics.webp` | Fotowoltaika |
| `heating-fireplaces.webp` | Kominki i ogrzewanie |
| `carpentry.webp` | Stolarka |
| `windows-doors.webp` | Okna i drzwi |
| `roofing.webp` | Dachy |
| `painting-facades.webp` | Malowanie i elewacje |
| `wedding-planning.webp` | Organizacja wesel |
| `floristry.webp` | Florystyka |
| `catering.webp` | Catering |
| `photography.webp` | Fotografia |

| `cleaning.webp` | Firmy sprzątające |

## Spec

- **Format:** WebP
- **Size:** **320 × 480 px** (2:3 portrait - taller than wide; do not crop or re-export to landscape)
- **Display:** top-aligned in the card (`object-contain object-top`); bottom fades into card background via gradient
- **Style:** real project / trade photography, dark-friendly (landing hero is dark)
